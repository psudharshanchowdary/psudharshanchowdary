> A full-stack web platform to streamline cloud kitchen operations end-to-end.

- **Real-time** order tracking with status flows: Pending → Preparing → Ready → Delivered
- **Kitchen Dashboard** with cooking timers, priority queues, and live updates
- **Inventory Management** with low-stock alerts and supplier tracking
- **Analytics Dashboard** with revenue trends and operational metrics
- **Stack:** Next.js · TypeScript · Spring Boot · MySQL · Tailwind CSS

### ☁️ AWS Automated Receipt Processor
> Serverless, event-driven expense management system on AWS.

- Automated pipeline: **S3 → Lambda → Textract → DynamoDB → SES**
- Extracts financial data from receipts with zero manual intervention
- Fully serverless, scalable, and production-ready
- **Stack:** Python · AWS Lambda · S3 · Textract · DynamoDB · SES

### 🌲 AI-Powered Forest Monitoring System *(Academic Research)*
> Intelligent deforestation detection using satellite imagery and deep learning.

- Built with **YOLOv8** and **Mask R-CNN** for object detection & segmentation
- Integrated **Sentinel-2 satellite imagery** with NDVI change analysis
- Deployed via **Streamlit** with **Google Earth Engine** backend
- Extends IEEE Access 2025 published research
- **Stack:** Python · YOLOv8 · Mask R-CNN · GEE · Streamlit · Docker
