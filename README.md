### Projects

**[AI Forest Monitoring & Impact Assessment](https://github.com/psudharshanchowdary/AI-Forest-Monitoring-Impact-Assessment)**
End-to-end satellite image segmentation pipeline for deforestation detection. Trains and compares YOLOv8-seg and Mask R-CNN on multispectral (RGB + NIR) satellite imagery with NDVI vegetation analysis. Includes a Streamlit dashboard, ONNX export, Optuna hyperparameter search, and Hugging Face deployment.  
`Python` `PyTorch` `YOLOv8` `Mask R-CNN` `ONNX` `Streamlit` `Google Earth Engine` `Optuna`

**[AWS Receipt Processor](https://github.com/psudharshanchowdary/aws-receipt-processor)**
Event-driven serverless pipeline for automated expense management. Ingests receipt files, extracts financial transaction data, and catalogs results using modern cloud engineering patterns — Lambda, S3, event triggers, and structured storage.  
`Python` `AWS Lambda` `S3` `Serverless` `Cloud Architecture`

**[Smart Residential Operations Platform](https://github.com/psudharshanchowdary/Smart-Residential-Operations-Platform)**
Full-stack, role-based housing management portal. Handles tenant communication, maintenance requests, and operational workflows across multiple user roles with proper auth and access control.  
`TypeScript` `React` `Node.js` `Role-Based Access Control`

**[Cloud Kitchen Management System](https://github.com/psudharshanchowdary/cloud-kitchen-management-system)**
Web-based operations system for cloud kitchens — order tracking, inventory management, and kitchen workflow coordination built for real operational use.  
`TypeScript` `Next.js` `Spring Boot` `MySQL`
