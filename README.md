### Projects

**[AI Forest Monitoring & Impact Assessment](https://github.com/psudharshanchowdary/AI-Forest-Monitoring-Impact-Assessment)**
End-to-end satellite image segmentation pipeline for deforestation detection. Trains and evaluates YOLOv8-seg vs. Mask R-CNN on multispectral (RGB + NIR) imagery with NDVI vegetation analysis, ablation study, ONNX export, and Streamlit dashboard.
![Tests](https://github.com/psudharshanchowdary/AI-Forest-Monitoring-Impact-Assessment/actions/workflows/tests.yml/badge.svg)
`Python` `PyTorch` `YOLOv8` `Mask R-CNN` `ONNX` `Streamlit` `Google Earth Engine` `Optuna`

**[AI-Based Object Detection — CCTV System](https://github.com/psudharshanchowdary/ai-based-object-detection)**
Real-time object detection system using YOLOv8 and OpenCV. Processes live webcam feed, draws bounding boxes, triggers configurable alerts, and saves timestamped detection snapshots.
`Python` `YOLOv8` `OpenCV` `Real-time` `Computer Vision`

**[Bloom Diagnose — Plant Disease Detection](https://github.com/psudharshanchowdary/bloom-diagnose-ml)**
AI-powered plant disease detection from leaf images. Classifies diseases across multiple crop types and returns treatment recommendations.
`Python` `TypeScript` `Machine Learning` `Image Classification` `Agriculture AI`

**[AWS Receipt Processor](https://github.com/psudharshanchowdary/aws-receipt-processor)**
Event-driven serverless pipeline for automated expense management on AWS. S3 → Lambda → Textract → DynamoDB → SES — zero manual intervention.
`Python` `AWS Lambda` `S3` `Textract` `DynamoDB` `Serverless`

**[Smart Residential Operations Platform](https://github.com/psudharshanchowdary/Smart-Residential-Operations-Platform)**
Full-stack, role-based housing management portal with tenant communication, maintenance workflows, and admin operations.
`TypeScript` `React` `Node.js` `RBAC`

**[Cloud Kitchen Management System](https://github.com/psudharshanchowdary/cloud-kitchen-management-system)**
Operations system for cloud kitchens — real-time order tracking, inventory management, and kitchen workflow coordination.
`TypeScript` `Next.js` `Spring Boot` `MySQL`
